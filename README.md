## PyHeat2D  


## Quick Setup 

For Quick Setup  is recommended  to use a virtual  environment to play with  

Following Step: 

1 > Create the virtual env 
```bash 
$ python3  -m venv <dist> 
```
2 > Activate the environment 

```bash
$ source dist/bin/activate
```

3 > Install  the required dependancies 

```bash 
$ python3  -m pip install -r requirement.txt
```


## BUILDING  MODULE  

We provide an Makefile  that help  to build cleanly
the base modules. 
You can take a look
just launch 
```bash  
$ make  && make init  
```

For cleaning or restoring back to default 
```bash 
$ make mproper   
```
